# Flight Tracker (Отслеживание самолетов в реальном времени)

Консольное приложение на Python для получения, фильтрации и анализа данных о воздушных судах, находящихся в воздушном пространстве выбранной страны в реальном времени.

## Функционал
- Получение географических границ (`boundingbox`) выбранной страны через API **Nominatim (OpenStreetMap)**.
- Запрос актуальных данных о самолетах в заданных координатах через API **OpenSky Network**.
- Сохранение уникальных записей о рейсах в JSON-файл (`data/aeroplanes.json`).
- Фильтрация самолетов по стране регистрации и диапазону высоты полета.
- Сортировка по убыванию высоты (при равной высоте — по скорости) и вывод топ-N рейсов в консоль.

## Структура проекта
- `src/api.py` — абстрактный класс и реализация для работы с внешними API.
- `src/aeroplane.py` — модель самолета с валидацией атрибутов и методами сравнения.
- `src/storage.py` — абстрактный класс хранилища и реализация сохранения в JSON.
- `src/utils.py` — вспомогательные функции фильтрации, сортировки и вывода.
- `tests/` — модульные тесты на `pytest` (покрытие > 90%).
- `main.py` — точка входа и консольный интерфейс взаимодействия с пользователем.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd flight_tracker
   ```

2. Установите зависимости через Poetry:
   ```bash
   poetry install
   ```

3. Запустите приложение:
   ```bash
   poetry run python main.py
   ```

4. Запустите тесты с проверкой покрытия кода:
   ```bash
   poetry run pytest --cov=src --cov-report=term-missing
   ```
